# 📋 Appendix A — Cheat Sheet

## The 10-Second Plan

```text
Who + situation + problem + offer + proof + channel + action + measure + limit
```

## Formulas

| Metric | Formula |
|---|---|
| CTR | clicks ÷ impressions |
| CPC | spend ÷ clicks |
| CPM | spend ÷ impressions × 1,000 |
| Conversion rate | conversions ÷ visitors (or stated base) |
| CPA | spend ÷ conversions |
| AOV | revenue ÷ orders |
| ROAS | attributed revenue ÷ ad spend |
| Contribution/order | net price − variable costs |
| Break-even CPA | contribution/order |
| Break-even ROAS | net price ÷ contribution/order |
| Target CPA | contribution − required amount left |
| Marginal CPA | added spend ÷ added conversions |
| CAC | acquisition cost ÷ new customers |
| Relative lift | (variant − control) ÷ control |

## Channel Picker

| Situation | Try first |
|---|---|
| Urgent local need | Business Profile, local search |
| Existing search demand | SEO, search ads |
| New visual product | short video, paid social |
| Existing customers with permission | email or WhatsApp |
| Narrow B2B market | partnerships, useful outreach, LinkedIn, search |
| High trust needed | reviews, experts, demonstrations |

## Page Check

- [ ] What, who and action are clear
- [ ] Page matches ad/search
- [ ] Price and important terms are visible
- [ ] Proof is true
- [ ] Objections answered
- [ ] Mobile, speed and keyboard tested
- [ ] Conversion tested once

## Campaign Check

- [ ] Contribution and loss limit known
- [ ] Audience and exclusions appropriate
- [ ] Creative ideas are truly different
- [ ] Claims, rights and disclosure approved
- [ ] UTMs valid
- [ ] Lead/order response ready
- [ ] Review rule written

## Report in Five Lines

```text
Result:
Evidence:
Likely explanation:
Uncertainty:
Next decision, owner and date:
```

## Red Flags

Guaranteed rankings · fake scarcity · unowned accounts · adding every platform's conversions together · optimizing for likes when sales are needed · changing five things at once · sending without permission · scaling because average ROAS looks good.
