# 🩺 Appendix F — Troubleshooting

First ask: **Did tracking, dates, offer, stock, season or definitions change?**

| Symptom | Likely causes | First fix |
|---|---|---|
| Traffic, no sales | mismatch, cost, trust, broken checkout | watch five people buy; split source/device |
| Many leads, no sales | weak qualification, slow reply | inspect 20 leads and response times |
| Ads spend nothing | status, billing, bid, low volume | platform diagnostics and eligibility |
| Spend jumped | budget, schedule, auction, duplicate campaign | change history and daily totals |
| Conversions doubled overnight | duplicate event/import | compare unique order IDs |
| Conversions disappeared | consent, tag, page or payment change | test complete journey |
| Search impressions fell | demand, season, indexing, ranking | split query/page/country/device |
| Page not indexed | blocked, duplicate, weak or undiscovered | live URL inspection and links |
| Local calls fell | hours, profile, competitor, demand | verify public facts and call route |
| Followers grow, sales don't | audience/job mismatch | qualified visits and buyer interviews |
| Video stops early | unclear opening, slow payoff | remove introduction; show result sooner |
| Email clicks fell | relevance, frequency, delivery | domain/provider and segment split |
| Email to spam | authentication, complaints, old list | stop inactive sends; verify setup |
| WhatsApp blocked/reported | weak permission, irrelevant pressure | pause promotion; fix consent/frequency |
| Good average CPA, weak growth | poor marginal return | calculate marginal CPA |
| Platform disagrees with shop | windows/definitions/overlap | reconciliation checklist |
| Test has no winner | small sample/effect | estimate interval; keep learning |
| Discount boosts orders, loses profit | margin/cannibalization | contribution and normal buyer comparison |
| AI output invents facts | missing evidence/control | approved fact IDs and human check |
| Automation sent twice | retry without deduplication | event ID and suppression |

## The Five-Step Diagnosis

1. Confirm the number.
2. Locate where it changed.
3. List competing causes.
4. Run the cheapest decisive check.
5. Change one main cause and record it.

> ⚠️ If privacy, unsafe claims or uncontrolled spending is involved, pause the affected activity first.
